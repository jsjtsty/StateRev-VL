# 第三晚总结（2026-09-24）

细节和所有数字见 `NIGHT_LOG.md` 第 6h–7n 节，预注册见 `PREREG.md` Addendum J–Q。

## 0. 一句话

- 我们推翻了自己的"模型内部有状态、只是说不出来"。
- 取而代之的发现有两条：
  1. 被遮挡的相同物体，模型根本不追踪。它靠外观重识别，而且会被中间画面干扰。
  2. 模型报告"现在"时，会被前一个画面污染（stale present）。这种干扰是前摄性的：最后一帧单独看全对，一放进视频就错。我们已把它定位到"问题文本在第 18–26 层检索视频"这个环节。

## 1. 被推翻的结论（重要）

- 之前"最终状态可解码 0.95"的探针用的是随机划分，被历史查表混淆了。
- 改用按历史分组留出后（测试集里的交换历史在训练中从未出现）：
  - 不透明杯子，k=1 就是 0.00；k=2–4 在随机水平以下。
  - 透明杯子为 1.00。
  - 4 个 Qwen 模型结果一致。
- 因此撤回三条结论："读出断层"、"内部逐步组合"、"深度衰减曲线"。

## 2. 杯子游戏的新机制（J/K，3 个模型）

| 条件 | 内部位置编码（留出历史） | 说明 |
|---|---|---|
| 相同杯子 | 随机水平 | 不做运动追踪 |
| 彩色杯子，完整视频 | 0.45–0.85 | 部分，靠外观 |
| 彩色杯子，交换期间空白或冻结 | 0.92–1.00 | 去掉中间画面反而更好 |
| 彩色杯子，逐步静止的中间排列 | 0.49–0.54 | 起破坏作用的是中间排列，不是运动 |

27B 的回答也是空白条件最好：0.86，完整视频 0.66。

## 3. 新现象：stale present（L–P）

**任务**：问"视频最后，左边位置是什么颜色"。答案在最后 0.5–4 秒一直清楚可见。

**前一个画面会污染"现在"**
- 最终画面停留 0.5 秒时，Qwen3-VL-8B 准确率 0.4–0.57。
- 错误几乎都是"倒数第二个画面"的答案（88–100%）。
- 只给最后一帧时，准确率是 1.00。

**触发条件**
- 需要至少两个同类的连续状态（m≥2）。只有"揭示画面加最终画面"时不出错。
- 需要多物体，或者以位置为索引的问题（"左边是什么"）。单个数字、单个球不出错。

**模型覆盖**
- 覆盖：Qwen2.5-VL-7B、Qwen3-VL 2B/4B/8B/32B、Qwen3.5-9B。
- 32B 在杯子排列上好很多，但最简单的圆点任务仍然只有 0.46。
- Qwen3.6-27B 完全没有这个现象。
- LLaVA-Video-7B 连单帧都看不清，所以不适用。

**不是分词伪影**
- 帧作为单独图片输入时，效应减弱但仍存在。
- 状态切换都对齐时间组边界，所以不是同一组里混进了新旧两帧。

**机制（Qwen3-VL-8B）**
1. 注意力没有"越新越重要"的偏好：最终画面和前一个画面得到的注意力一样多。
2. 在所有文本位置上只遮蔽前一个画面：准确率 0.60 → 0.81，stale 答案 0.33 → 0.08。只在第 18–26 层遮蔽就有全部效果，其他层段无效或很弱。
3. 检索分布在问题的各个 token 上，最后一个 token 单独贡献很小。第 24–27 层的"相关头"并没有因果作用（Addendum Q 被否定）。
4. 剩余的约 0.2 来自视频编码本身的污染。

**修复**
- 在视频后附上最后一帧：部分有效。Qwen3.5 提升很多，Qwen3-VL 提升有限。
- 写出推理：效果不一致。模型描述中间过程时会幻觉出不存在的排列。

## 4. 前景判断

**可能的论文主线**："Video VLMs misread the present"。

**支撑它的三点**
1. 一个简单、稳健、跨 3 代 7 个模型的行为现象，并且有严格对照：只看单帧、只有单个物体、只变化一次，这些条件下都不出错。
2. 能精确定位：文本在第 18–26 层检索视频时混入了旧状态，另有一部分来自编码阶段。
3. 和杯子游戏的发现互相呼应。杯子游戏里，"中间画面干扰外观重识别"是更大的故事。"不做运动追踪"加上"按历史留出的探针方法论"可以作为第二部分。

**风险**
- 最新的 Qwen3.6-27B 已经没有这个问题。审稿人可能认为它会被模型迭代自然解决。
- 反驳依据：Qwen3-VL-32B 仍有这个问题；另外，杯子游戏里的中间画面干扰在 27B 上同样存在。

**下一步建议**
1. 在真实视频上验证，比如桌面物品被重新摆放后，问"最后某个位置是什么"。
2. 如果有商业 API，测一下闭源模型（GPT、Gemini）。
3. 训练无关的修复：只在第 18–26 层做"最近状态注意力偏置"。需要在无标签条件下检测变化点。
4. 把"按历史留出"做成一节方法论。
